⚠️ Troubleshooting quick start

Low lube-oil pressure

Check local gauge → transmitter value → filter differential pressure → pump status → suction conditions → oil temperature/viscosity. Compare local and remote readings before changing a sensor.

High jacket-water temperature

Compare inlet/outlet temperature → check cooling-water pressure/flow → cooler condition → control valve → load and cylinder temperature deviations.

High exhaust temperature on one cylinder

Compare all six cylinder TC values → verify sensor wiring/terminal condition → compare with local/independent measurement → investigate injection, exhaust valve and combustion condition.

ME-GI gas pressure abnormal

Check gas-system pressure transmitters and valve feedback → confirm permissives/interlocks → compare ECS indication with local instrumentation → follow the approved gas-system procedure.
